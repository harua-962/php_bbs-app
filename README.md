# ひとこと掲示板アプリ (PHP基礎学習)

PHPとMySQLを使用して作成した、データの投稿・保存・一覧表示ができるWebアプリです。

## 使用技術
* HTML / CSS
* PHP
* MySQL (XAMPP)

## 機能
* 投稿フォームからのデータ送信
* データベースへの保存
* 保存データの読み込みと一覧表示
* XSS対策 (htmlspecialchars)

## データベース設定
同梱の `php_lesson.sql` をインポートして使用します。
